# Clyro Demo Script — Main User Journey

## User Journey Walkthrough

### 1. Student Onboarding & Membership Request
- Log in as Student (`student@msot.edu`).
- Browse available clubs (showing 3 independent clubs and the 4 society sub-clubs).
- Request membership in a Society Sub-Club (e.g., *Web & Cloud Sub-club*).

### 2. Coordinator Approval
- Switch profile/role to Student Coordinator (`coordinator@msot.edu`).
- Review pending membership requests for assigned sub-club.
- Approve student membership.

### 3. Club Day Activity Creation & Advisor Approval
- Coordinator creates an activity plan (Title, topic, deliverable requirements, submission deadline).
- Switch to Faculty Advisor (`advisor@msot.edu`).
- Review the proposed activity and click **Approve Activity**.

### 4. Live Attendance Check-In
- Coordinator launches live Club Day session with rotating 6-digit code and QR code.
- Student enters 6-digit code or scans QR on phone.
- Verify attendance marked as **Present** with timestamp.
- Attempt second check-in to demonstrate duplicate prevention.

### 5. Work Submission & Rubric Evaluation
- Student uploads activity deliverable (presentation link or report).
- Coordinator/Advisor opens submission review modal.
- Evaluates according to rubric (Content, Presentation, Participation).
- Scores and feedback immediately reflect on student dashboard.

### 6. Society & College Dashboards
- Switch to Society Administrator: View consolidated statistics across all 4 sub-clubs without double counting.
- Switch to College Admin: Inspect global participation across all 4 top-level entities.
- Issue and verify tamper-proof PDF certificate.
